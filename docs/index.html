Core commands

These are the commands you’ll use daily.

embit init my_app

Initialize a new project workspace.

embit clone ignite --into my_app

Clone an EVLOV IGNITE kit into your project.

embit feature auth --with bloc --with tests

Scaffold a feature module with patterns + tests.
