CLI that developers actually enjoy

The CLI is the front door: it makes kits easy to use, features easy to generate, and help easy to find.

Init

Start projects the same way every time with `embit init`.

embit init my_app

Clone

Get kits and templates from your marketplace with `embit clone`.

embit clone ignite --into my_app

Feature

Generate consistent features with `embit feature` so structure doesn’t drift.

embit feature auth --with bloc --with tests

Help

Discover commands and examples quickly with `embit help`.

embit help
