Why Ignite

Strong defaults so you can start building features immediately.

Ready structure

Opinionated folders and patterns that fit small-to-medium apps without over-engineering.

CLI-friendly

Pairs with `embit clone` + `embit init` so your setup stays repeatable across projects.

Feature scaffolding

Generate new features consistently using `embit feature`—avoid copy/paste and drift.

How to use it

The workflow is the product: clone → init → build features.

embit init my_app embit clone ignite --into my_app embit feature home --with bloc embit help
