How it works

A simple flow: setup the CLI, bring a kit/template, then clone into your project.

Step 1

CLI setup

Install Embit CLI and create the Embit environment.

embit setup

~3 minutes

Step 2

Kit/template setup

Download a kit (start with EVLOV IGNITE), then clone from its path.

embit clone <path-to-kit>

~3 minutes

Step 3

Project setup

Create a Flutter app, then choose a downloaded kit/template to clone in.

flutter create my_app
cd my_app
embit clone --kit
# or
embit clone --template

~5 minutes
